# أدوات المطوّر (ما بتدخل بالموقع المنشور)

سكربتات Node بتولّد ملفات ثابتة بالمشروع. كلها اختيارية: الملفات الناتجة موجودة وجاهزة بالمستودع، وبتشغّل السكربت بس لما تغيّر الشعار أو شكل البرنامج أو الأيقونات.

بتحتاج Playwright (`npm i -g playwright` أو أي مكان يلاقيه `require('playwright')`).

| السكربت | شو بيعمل |
|---|---|
| `make-icons.cjs` | بيرسم كل أيقونات PNG (96/192/512، القابلة للقص، آيفون، وأيقونة التطبيق المكتبي 1024) من شعار «كنز» بـ`tools/logo/` |
| `store-assets.cjs` | بيصوّر البرنامج الحقيقي ببيانات العرض التجريبية ويولّد صور نافذة التثبيت والمتجر (`ahsebha/store/`: صور الجوال والعريضة وصورة العرض 1024×500). بدّه خادم محلي: `python3 -m http.server 8765` من جذر المستودع |
| `build-icons-data.cjs` | بيولّد `ahsebha/js/icons-data.js` (الأيقونات المضمّنة بالبرنامج) من Lucide وSimple Icons. لإضافة أيقونة جديدة أضفها لقائمة `EMOJI` أو `EXTRA` داخله ثم شغّله (التفاصيل بأول الملف) |

## الشعار (`logo/`)
- `icon.svg`: شعار «كنز» الرئيسي (قطعة ذهبية فيها حرف ك على مربع نيلي). نسخة طبق الأصل منه بـ`ahsebha/icons/icon.svg`: عدّل الأصل هون وانسخه هناك، و`make-icons.cjs` بينبّهك إذا اختلفا.
- `icon-bleed.svg`: نفس الشعار والخلفية بتملأ المربع كله (أيقونة أندرويد القابلة للقص وآيفون).
- `word-dark.svg` و`word-white.svg`: كلمة «كنز» مرسومة من حروف خط IBM Plex Sans Arabic (ترخيص OFL) على خلفية فاتحة أو داكنة.

## التراخيص
- الخط IBM Plex Sans Arabic: SIL Open Font License 1.1 (النص بـ`ahsebha/fonts/OFL.txt`).
- الأيقونات: Lucide (ISC) وSimple Icons (CC0)، نصوص التراخيص بأول `ahsebha/js/icons-data.js`.
