# احسبها لسطح المكتب

نافذة Electron بتفتح برنامج احسبها كتطبيق مثبّت (أيقونة ونافذة لحالها، مش متصفح): ويندوز، ماك، ولينكس.

## كيف بيشتغل
- التطبيق بيعرض الواجهة من موقع البرنامج (`https://ooo518106-rgb.github.io/ahsebha/`)، فكل تحديث للبرنامج أو للباقات والميزات بيوصل لكل المستخدمين فوراً بدون إعادة تثبيت. ومعه نسخة كاملة من البرنامج داخل ملف التثبيت (`extraResources`)، فبيشتغل بدون إنترنت حتى من أول تشغيل. الشبكة أولاً دائماً؛ وإذا تعذّرت بيعرض آخر نسخة نجحت على الجهاز، وبعدها النسخة المرفقة (`offline-site.js`).
- البيانات المحاسبية بتنحفظ داخل التطبيق على الجهاز (IndexedDB) ومنفصلة عن المتصفح؛ بتنقلها بنسخة احتياطية من «الإعدادات».
- مرفقات PDF بتنفتح ببرنامج الـPDF عندك (بتنحفظ مؤقتاً وبتنمسح بعد أسبوع)، وروابط واتساب والمواقع بتفتح بمتصفح الجهاز، ورابط لصفحة من البرنامج (مثل مستند مكرر) بيفتح نافذة جديدة للتطبيق.
- الصوت العربي لـ«ملخص اليوم» بيستخدم أصوات النظام فقط (ويندوز: الوقت واللغة ← الكلام ← إضافة أصوات ← العربية)، لأن أصوات Google الإضافية موجودة بمتصفح Chrome وحده.
- الأمان: بدون Node بالصفحة (`contextIsolation` و`sandbox`)، ونافذة التطبيق بتعرض صفحات البرنامج بس؛ أي رابط خارجي (واتساب مثلاً) بيفتح بمتصفح الجهاز. الصلاحيات: الكاميرا للباركود وصور الإيصالات بدون الميكروفون. القواعد بـ `policy.js` ومختبَرة.

## تجربة محلية
```bash
cd desktop
npm ci
npm start                                    # يفتح الموقع الحقيقي
AHSEBHA_URL=http://127.0.0.1:8765/ahsebha/ npm start   # أو نسخة محلية
npm test                                     # اختبار قواعد التنقل والصلاحيات
```

## البناء والنشر
البناء بيصير على GitHub Actions (`.github/workflows/desktop.yml`) لأن ملفات ويندوز وماك بدها أجهزتها:
- كل تعديل على `desktop/` بيبني الثلاث منصات وبيشغّل **اختبار تشغيل** فعلي على كل واحدة (بيفتح التطبيق ويتأكد إن البرنامج ظهر والتخزين والتوقيع الرقمي شغّالين).
- لنشر إصدار: Actions ← «تطبيق سطح المكتب» ← Run workflow ← فعّل `release`. (أو وسم `desktop-v1.0.0`.) بيتنشر بصفحة Releases بأسماء ثابتة، فروابط `releases/latest/download/…` ما بتتغير.
- رقم الإصدار من `package.json`. غيّره قبل كل إصدار جديد.

## تحديث التطبيق نفسه
البرنامج (الواجهة والميزات والباقات) بيتحدّث لحاله. أما الغلاف (نسخة Electron وChromium) فبيتحدّث بنشر إصدار جديد من التطبيق من وقت لوقت لأسباب الأمان: ارفع `electron` بـ `package.json` وغيّر رقم الإصدار وشغّل البناء. ما في تحديث تلقائي للغلاف حالياً (بدو توقيع رقمي أولاً).

## التوقيع الرقمي (لسّا ما اتعمل)
الملفات غير موقّعة، فبيطلع تحذير أول مرة (SmartScreen على ويندوز، وGatekeeper على ماك) والتفاصيل بـ `RELEASE_NOTES.md`. لإزالته: شهادة توقيع كود لويندوز، وحساب Apple Developer مع التوثيق (notarization) لماك. بيحتاجوا حسابات على اسم المالك.
